# GRAND-2 — 60+ тиков городской жизни + квест (2026-07-14, после сшивки)

Свежий мир, точный старт (вечер, 12 монет). Три фазы одного приключенца. Тиков: A 48+ · B 49 · C ~30 = 120+.

|---|---|
| Городская жизнь (потоки/капы/уходы) | **PASS** — «зал редеет — вышли 10» + каскад Розы; комната ограничена; свои дела у всех |

## РЕАЛЬНЫЕ НАХОДКИ (фикс-батч)
1. **[баг] dict-имена вещей**: 30 из 1354 персон пула несут valuables-словарь ({'item','cost'}); _put_item
   не санирует → «За «{'item': 'Медная пуговица'…}»? 14» в торге. Фикс: санация на материализации.
2. **[трещина] гео-шэйр на здание, где игрок стоит**: Хельга изнутри «Гнилого зуба»: «Ступай в Гнилой
   зуб, минута ходу к югу». Фикс: target bid == текущее здание → «да ты уже здесь».
3. **[робастность] /room и /zone 500** на пустом/кривом теле. Фикс: честная ошибка.
4. **[проверить] ложная фамильярность на свежем мире**: «Снова на Костяном Мосту», «в прошлый раз не
   разбежались» незнакомцу. Найти источник (greet-промпт? сид aff?).
5. **[мелочь] несогласованность подателя**: title дела «зачистить для Гильдия «Устье»», бит — «поручение
   Обер Косой». Едино: инцидент = податель-человек, гильдия = канал.
6. **[дизайн, юзеру] летальность боя для новичка**: безоружные 18 hp vs 2 крысы (cr 0.92) = −9 hp/раунд;
   порог «бегу при hp<8» непроходим (18→9→0 за два раунда). Вопрос баланса/UX намеренности.

## ЛОЖНЫЕ ТРЕВОГИ (сняты проверкой)
- «Фантомная атака сожгла ход» — код: err → ранний return БЕЗ end_turn/AI; смерть = промах+2 попадания.
- «Мир сброшен между фазами» — один процесс, один newworld (контроллера); gt-телеметрия фазы A выдумана
  (сон был подарком 2 зм + нарративом, не механикой) — фаза B честно играла вечер дня 1.
- «Хельга/Юна пропали» — анпин: люди разошлись по своим делам. Это фича.
- «Данж не навигируется» (фаза B) — бриф контроллера не дал dungeon_move; с полным API — 5 комнат без запинки.
- «LLM timeout cascade» — 5-сек таймаут собственного bash тестера.
