## ТРЕЩИНЫ — подтверждено/опровергнуто

- **[ПОДТВЕРЖДЕНО] Выдуманная общая история.** Обер: «славно ты тогда меня выручил» (река). БД:
  affinity 0.0, anchored False, НИ ОДНОЙ памяти об игроке → faint-тир корректно активен, промпт
  «не выдумывай общих дел» стоит — LLM (deepseek) его нарушил. Класс: комплаенс нарратора.
- **[ПОДТВЕРЖДЕНО] Путаница имён.** pool:0114 = «Гвен Косой» (БД); Лия назвала её «Гвен Полынь»;
  Бета назвала игрока «Гвен Косой». Инструкция «не путай с другими посетителями» в voice.py есть —
  нарушается. Тот же класс.
- **[ОПРОВЕРГНУТО] «fear 0.85 у жертвы кражи — баг».** Действие было силовым/наглым → грабёж →
  страх по спеке (ev_victim_rel_fear при threat>0). Чистая карманная кража страха не даёт (покрыто
  тестами test_victim_branch).
- **[ОПРОВЕРГНУТО] «эмоции статичны».** Аффект двигается (Обер +0.09 fear, Ирма эмоция сдвинулась),
  просто фронтирные значения черт дают малые дельты и нарратив их не озвучивает.

## Вывод по программе

Юнификация (U1-U5 + хвост /steal) **живьём подтверждена**: жертва получает гнев+якорную обиду через
единую дверь, менейс долетает сквозь линзу смелости, знакомство faint-тира активно. Остаточные
трещины — качество LLM-нарратора (выдуманная история, путаница имён), НЕ регрессия рефактора.
