# ОСНОВНОЙ СЮЖЕТ — диздок (решения зафиксированы)

Из небольшого сида генерим сюжет: каст трёх категорий (враги / союзники / важные нейтралы),
**иерархия** и **важность в повествовании** — два РАЗНЫХ измерения. Сюжет читается как книга
и живёт внутри существующих механик. **Игрок — РЕГРЕССОР**: он уже прожил этот кошмар и
ЗНАЕТ врагов в лицо. Драма не «кто злодей», а «как остановить, зная всё, но будучи никем».

## 0. Ядро идеи

Сюжет — книга, распластанная по живому городу. Город УЖЕ живой (mind, агенды, сплетни,
распорядок) — сюжет не строит второй мир, а **нанизывается на существующих людей** (80%
каста — placed NPC из пула; новички только там, где матчер не нашёл персону).

**Регрессор знает только ОБЩЕЕ.** В прологе книги — «прошлая жизнь», но память крупными
мазками (3-6 пунктов): культ существует, исчезновения не случайны, беда идёт по расписанию,
страже верить нельзя, чем всё кончилось. Помнит 2-6 СМУТНЫХ лиц («этот считал монеты культа
— и пил») — но НЕ антагониста-в-тени: «правда» библии скрыта и от игрока, её добывают заново.
Знание «ЧТО происходит» без «КТО и КАК» — фора, а не спойлер. При этом:
- **доказательств нет** — пойдёшь к страже с «повитуха — глава культа» → ты чужак-клеветник
  (а стража уже куплена);
- **сил нет** — врагов 12+, у них иерархия, деньги и город;
- **память несовершенна** — регрессор помнит СОБЫТИЯ прошлого цикла, не души людей: тайные
  арки, слабые звенья, секреты нейтралов надо открывать заново; и минимум один узел, где
  память ВРЁТ («в этот раз иначе» — обязательный реверс «память подвела»);
- **союзники не помнят** — их надо вербовать с нуля, зная о них больше, чем они сами о себе.

## 1. Вход: сид → библия сюжета (генерация СРАЗУ при создании мира)

LLM-роль `plot_architect`: сид (из профиля города) + фракции + срез placed NPC → **библия**
(структурный JSON, персист на мир). Генерация — лениво в фоне после постройки мира; до
готовности город живёт обычной жизнью; фоллбэк — StubArchitect (шаблонная библия).

```
{
  "тема":    "цена безопасности — чужая свобода",
  "конфликт":"культ выкупает город у беды, платя людьми",
  "тайна":   "исчезновения — «добровольные» жертвы",          // тайна для ГОРОДА, не для игрока
  "правда":  "бургомистр — заложник; глава — повитуха",        // регрессор ЗНАЕТ с пролога
  "прошлый_цикл": "чем кончилось в прошлый раз (пролог книги + память регрессора)",
  "дельта":  [ "что в ЭТОТ раз пойдёт иначе (1-2 узла, где память врёт)" ],
  "входы":   [ ... 4-6 точек контакта, раскиданных по миру ... ],
  "акты":    [ ... 3 акта ... ],
  "каст":    [ ... 30+ актёров ... ]
}
```

«Правда» фиксируется при генерации — все проявления обязаны ей не противоречить.

**Точки контакта (входы)** — раскиданы по миру, независимы, каждая тянет свою нить акта I:
объявление на доске (пропавший), слух в таверне, письмо с двойным дном в лавке, ночная
сцена на улице, «знакомый из памяти» (регрессор помнит: этот человек — жертва №3, он ещё
жив — успей). Игрок сам выбирает, с какой стороны атаковать сюжет.

## 2. Каст: 30+ актёров, три категории × два измерения

Структура: **враги 12-15** (иерархия ≥4 уровней: глава-в-тени, фасад, 2-3 лейтенанта,
рядовые/купленные), **союзники 8-10**, **нейтралы 8-10**. Важность: 3-5 актёров с 8-10,
~10 средних, остальные — ткань города, втянутая в историю.

```
{
  "категория": "враг | союзник | нейтрал",
  "роль":      "архетип (меню ниже)",
  "иерархия":  {"структура": "культ", "ранг": 3, "подчиняется": "cast:2"},
  "важность":  8,                        // вес в ПОВЕСТВОВАНИИ — НЕ равен рангу!
  "желание":   "чего хочет сам",
  "секрет":    "что скрывает (гейт: как узнать)",
  "арка":      "путь изменения (перевербовка/падение/жертва) — или null",
  "память":    "что регрессор помнит о нём из прошлого цикла (может быть неточно!)",
  "актёр":     "pool:0483 | NEW",
  "чехов":     "чем выстрелит в кульминации (обяз. для важности ≥ 7)"
}
```

**Иерархия ≠ важность — несущая балка.** Валидатор ОБЯЗУЕТ: минимум один враг «ранг высокий /
важность низкая» (фасадный босс-функция) и минимум один «ранг низкий / важность ≥8» —
**правда живёт внизу** (колеблющийся казначей, а не иерарх). Реверсы опираются на разрыв осей.

**Меню архетипов** (данные): антагонист-в-тени, фасадный лидер, правая рука, слабое звено,
фанатик, наставник, скрытый союзник, предатель-среди-своих, ложный след, свидетель,
сердце истории, разменная пешка, торговец-обеим-сторонам.

**Кастинг:** матчер нанизывает актёров на placed NPC по роли/персоне/связям (повитуха-глава →
знахарка из пула; казначей → лавочник при гильдии). 80% — существующие лица.

## 3. Драматургия регрессора: чтобы читалось как книга

Три акта — не «узнать правду», а «добыть силу её доказать/применить»:
- **Акт I «Никто»**: игрок знает всё — и не может ничего. Задача акта: зацепки-доказательства
  + первые союзники (вербуешь, зная их лучше их самих). Город видит аномалию, верит ложному
  следу. Реверс: первая «дельта» — память подвела (слабое звено уже мертво / жертва не та).
- **Акт II «Паутина»**: подрыв иерархии врага изнутри: перевербовка слабого звена, стравливание
  лейтенантов, кража бухгалтерии жертв. Враг ЗАМЕЧАЕТ, что кто-то знает слишком много —
  охота разворачивается на игрока (стража куплена: розыск, наёмники). Город деградирует.
- **Акт III «Цена»**: кульминация — штурм/ритуал/суд; все «чеховы» стреляют. Развязка меняет
  город насовсем. Плохой финал (см. doom) — тоже финал: книга дописывается тьмой.

**Правила (валидирует код, не вкус LLM):**
1. Чехов: важность ≥7 и улики акта I стреляют в акте III.
2. Каждый реверс — на разрыве иерархия↔важность ИЛИ на «дельте» памяти.
3. 2-3 арки, минимум одна доступна игроку (befriend/дары/шантаж — есть на проде).
4. Фигуры: 1-2 из меню, спрятаны в касте.
5. Тема окрашивает нарратора и хрониста.

## 4. Движок: жёсткий doom clock + существующие механики

**Doom clock ЖЁСТКИЙ — последствия от инактива.** У врага расписание (по памяти прошлого
цикла ±дельта): каждые N дней — шаг: новая жертва (реальный NPC исчезает!), куплен стражник,
союзник запуган/убит. Регрессор ЗНАЕТ расписание — в этом его сила и его пытка: успеть.
Бездействие → город реально деградирует → «культ победил»: не пермасмерть, но необратимый
тёмный статус мира, книга дописана плохим финалом. Спасённые в срок NPC — живут.

| Механика (на проде) | Использование сюжетом |
|---|---|
| Агенды NPC (mind) | заговорщики встречаются; слабое звено пьёт в одиночку; охота на игрока |
| Сплетни/gossip | foreshadowing; и КОНТРразведка врага (сболтнул лишнего — культ узнал) |
| Контракты из агенд | «найди пропавшего», «отнеси письмо не читая» (а можно прочесть) |
| Доска/гильдия | заказы, зачищающие следы врага (игрок — невольный соучастник) |
| Предметы hidden+гейт | улики: письмо с двойным дном, амулет культа, бухгалтерия жертв |
| Суб-локации/ключи | тайники, запертые комнаты с уликами |
| Стража/розыск | куплена: копаешь → на тебя вешают дела; «клевета» на повитуху = розыск |
| Логова/battlemap | кульминации актов — процедурные подземелья из истории |
| Магия (гримуар) | ритуальные круги культа = рисунки по нашей грамматике; их можно ПРОЧЕСТЬ |
| Живая сцена | актёры шепчутся/замолкают при игроке (сюжетный слой агенд) |

**Тик сюжета:** дешёвый механический чек каждый ход мира (зацепки, doom-шаги по расписанию)
+ редкий LLM `plot_director` на границах актов. Остальное время сюжет живёт БЕЗ LLM.

## 5. Хроника-книга (в первом срезе)

Вкладка «Книга»: пролог = прошлый цикл (память регрессора). LLM-хронист (`chronicler`) после
каждой сюжетной сцены пишет страницу — литературно, в тоне темы, от третьего лица. Главы =
акты. Скачивается целиком: по завершении это повесть о твоём прохождении.

## 6. Роли LLM и что детерминировано

- `plot_architect` (1 вызов на мир, фоном): сид → библия (30+ каст — возможно, батчами).
- `plot_director` (границы актов): реверсы, коррекция агенд каста.
- `chronicler` (сюжетные сцены): страницы книги.
- Детерминировано: валидатор библии (§3), кастинг-матчер, плот-граф, зацепки-предметы
  (item_smith по шаблону), doom clock, «правда не противоречит».

## 7. Срез (этапы)

- **С-1**: `src/aidnd/plot/` — схема библии + валидатор + `plot_architect`/Stub + кастинг-матчер;
  фоновая генерация при создании мира; память регрессора в журнале; стенд /plotdebug.
- **С-2**: входы-зацепки через предметы/контракты/сплетни/доску; плот-граф; акт I играбелен.
- **С-3**: сюжетный слой агенд каста + жёсткий doom clock (жертвы реальны); акты II-III,
  кульминация через боёвку/подземелье; охота врага на игрока.
- **С-4**: хроника-книга (пролог + главы + скачивание).
- **С-5**: полировка: дельты памяти, перевербовка, финалы (включая тёмный).

## 8. Решения (бывшие вопросы)

- С1: генерация СРАЗУ при создании мира (фоном). С2: 4-6 точек контакта раскиданы по миру.
- С3: кастинг 80% на существующих placed NPC. С4: doom ЖЁСТКИЙ — последствия от инактива,
  возможен тёмный финал (шрам мира, не пермасмерть). С5: книга-хроника в первом срезе.
- С6: игрок — РЕГРЕССОР, знает врагов с пролога; на сторону врага не встаёт.
- С7: каст 30+ (враги 12-15 с иерархией ≥4 уровней, союзники 8-10, нейтралы 8-10).
