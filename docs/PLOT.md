# ОСНОВНОЙ СЮЖЕТ — диздок (черновик к обсуждению)

Цель: из НЕБОЛЬШОГО описания («в городе исчезают дети, а новый бургомистр слишком спокоен»)
генерировать полноценный сюжет: действующих лиц трёх категорий (враги / союзники / важные
нейтралы), их **иерархию** и их **важность в повествовании** — и это ДВА РАЗНЫХ измерения.
Сюжет должен читаться как книга и жить внутри уже существующих механик города.

## 0. Ядро идеи

Сюжет — не цепочка квестов, а **книга, распластанная по живому городу**. У неё есть тема,
тайна, антагонист со своим расписанием и правда, которую предстоит раскопать. Игрок не
«выполняет задания» — он ходит по городу, говорит с людьми, ворует письма, дерётся, колдует —
и страницы книги переворачиваются сами. Всё, что игрок уже умеет делать в игре, — это и есть
способы двигать сюжет.

**Главный принцип:** город УЖЕ живой (mind, агенды, сплетни, распорядок). Сюжет не строит
второй мир — он **нанизывается на существующих людей**. Трактирщик, у которого ты неделю
пьёшь эль, оказывается союзником. Стражник с площади — купленным врагом.

## 1. Вход: сид → библия сюжета

LLM-роль `plot_architect` получает: сид (1-3 фразы) + профиль города (имя, ключевые здания,
фракции-роли: гильдия/стража/храм/маги) + срез реальных placed NPC (роли, персоны, связи).
Выдаёт **библию сюжета** (структурный JSON, персист на мир):

```
{
  "тема":     "цена безопасности — чужая свобода",       // о чём книга (незримо правит тоном)
  "конфликт": "культ выкупает город у беды, платя людьми",
  "тайна":    "исчезновения — не похищения, а «добровольные» жертвы",
  "правда":   "бургомистр — не глава культа, а его заложник; глава — повитуха",
  "акты":     [ ... 3 акта, см. §3 ... ],
  "каст":     [ ... 9-15 актёров, см. §2 ... ]
}
```

«Правда» пишется СРАЗУ (гримуарный принцип: закон мира фиксирован до начала) — дальше
все проявления обязаны ей не противоречить. Никакой ретконной импровизации.

## 2. Каст: три категории × два измерения

Каждый актёр:

```
{
  "категория": "враг | союзник | нейтрал",
  "роль":      "архетип в истории (см. меню ниже)",
  "иерархия":  {"структура": "культ", "ранг": 3, "подчиняется": "casf:2"},
  "важность":  8,                       // вес в ПОВЕСТВОВАНИИ, 1-10 — НЕ равен рангу!
  "желание":   "чего хочет (двигает его сам)",
  "секрет":    "что скрывает (гейт: как узнать)",
  "арка":      "как может измениться (перевербовка/падение/жертва) — или null",
  "актёр":     "pool:0483 | NEW",       // нанизан на реального NPC из мира
  "чехов":     "чем выстрелит в кульминации (обяз. для важности ≥ 7)"
}
```

**Иерархия ≠ важность — это несущая балка дизайна.** Повороты сюжета живут именно в разрыве:
- иерарх культа: ранг 1, важность 4 — фасад, функция, «босс на бумаге»;
- казначей культа: ранг 3, важность 9 — колеблется, ненавидит, знает бухгалтерию жертв —
  и через него сюжет вскрывается;
- девочка-нейтрал: вне иерархий, важность 10 — следующая жертва, сердце истории.

Генератор ОБЯЗАН выдержать: минимум один враг с высокой иерархией и низкой важностью,
минимум один актёр с низкой иерархией и важностью ≥ 8 («правда живёт внизу»).

**Меню архетипов ролей** (данные, не хардкод поведения): антагонист-в-тени, фасадный лидер,
правая рука, слабое звено, фанатик, наставник, скрытый союзник, предатель-среди-своих,
ложный след, свидетель, сердце истории, разменная пешка, торговец-обеим-сторонам.

**Кастинг на живых людей:** матчер подбирает под каждого актёра существующего placed NPC
(по роли/персоне/связям: повитуха-актриса → знахарка из пула; казначей → лавочник при
гильдии). Совпало — актёр «нанизан»: его агенды, память и реплики получают сюжетный слой.
Не совпало — генерим нового значимого NPC из пула незанятых (портреты уже есть).

## 3. Драматургия: чтобы читалось как книга

**Три акта, каждый — со своим вопросом, реверсом и переменой города:**
- Акт I «Трещина»: аномалия видна, объяснение — ложное (ложный след указывает на нейтрала).
  Реверс: улика, ломающая удобную версию. Город: тревога, первые слухи.
- Акт II «Паутина»: игрок видит структуру (иерархию!) врага — и она врёт: фасадный лидер
  не тот. Реверс: предатель/слабое звено раскрывается (арка). Город: стража куплена,
  комендантский час, цены ползут.
- Акт III «Правда и цена»: правда вскрыта, кульминация (штурм/суд/ритуал/сделка), развязка
  меняет город НАСОВСЕМ. Каждый «чехов» выстреливает.

**Правила драматургии (валидируются кодом, не вкусом LLM):**
1. **Правило Чехова:** актёр с важностью ≥7 и предмет-улика из акта I обязаны сыграть в акте III.
2. **Разрыв осей:** каждый реверс обязан опираться на несовпадение иерархии и важности.
3. **Арки:** 2-3 актёра имеют путь изменения; хотя бы один — доступный игроку (перевербовать
   слабое звено через befriend/дары/шантаж — механики уже есть).
4. **Фигуры:** генератор выбирает 1-2 из меню (ложный след, скрытый союзник, предатель) —
  и прячет их В КАСТЕ, не в тексте.
5. **Тон:** тема книги окрашивает всё (нарратор получает тему в промпт).

## 4. Движок: как сюжет живёт в мире

**Плот-граф**: акты = узлы с зацепками (clues). Зацепка = конкретное проявление в существующей
механике. Акт открывается, когда собрано N из M зацепок (не все — есть свобода пути).

| Механика (есть на проде) | Как её использует сюжет |
|---|---|
| Агенды NPC (mind) | заговорщики встречаются, слабое звено пьёт в одиночку, союзник ищет игрока |
| Сплетни/gossip | foreshadowing: слухи акта II слышны уже в акте I |
| Контракты из агенд | «найди пропавшего», «отнеси письмо — не читая» (а прочитать можно) |
| Доска/гильдия | заказы, которые НА САМОМ ДЕЛЕ зачищают следы врага (игрок — невольный соучастник) |
| Предметы hidden+гейт | улики: письмо с двойным дном, амулет культа, бухгалтерская книга |
| Суб-локации/ключи | запертые комнаты с уликами, тайник в подвале |
| Стража/розыск | куплена врагом: копаешь глубоко → на тебя вешают дела |
| Логова/battlemap | кульминация акта — процедурное подземелье из истории (T8 уже умеет) |
| Магия (гримуар) | ритуальные круги культа = рисунки по нашей же грамматике; их можно ПРОЧЕСТЬ |
| Живая сцена | актёры в таверне ведут себя по сюжетному слою (шепчутся, замолкают при игроке) |

**Автономность антагониста (doom clock):** у врага есть расписание (каждые N дней — шаг:
новая жертва, куплен ещё стражник, союзник запуган). Мир давит, книга движется даже без
игрока — но пейсинг мягкий/жёсткий — вопрос С4.

**Тик сюжета:** дешёвый механический чек на каждый ход мира (собраны ли зацепки, сработал ли
doom-шаг) + редкий LLM-вызов `plot_director` на границах актов (оформить реверс, скорректировать
агенды актёров под новое состояние). Всё остальное время сюжет живёт БЕЗ LLM — через агенды.

## 5. Хроника-книга

Журнал получает вкладку «Книга»: LLM-хронист (роль `chronicler`) после каждой сюжетной сцены
пишет страницу — литературно, от третьего лица, в тоне темы. Главы = акты. Пролог генерится
из библии при старте. Книгу можно читать и СКАЧАТЬ целиком (как debuglog) — по завершении
сюжета это буквально повесть о твоём прохождении, с твоими выборами и твоими мертвецами.

## 6. Роли LLM и что детерминировано

- `plot_architect` (1 вызов на мир): сид → библия. Дорогой, качественный.
- `plot_director` (на границах актов): реверс, коррекция агенд каста.
- `chronicler` (после сюжетных сцен): страницы книги.
- Детерминировано (без LLM): валидатор библии (правила §3), матчер кастинга, плот-граф,
  zацепки-предметы (item_smith по шаблону), doom clock, проверка «правда не противоречит».

## 7. Первый срез (этапы)

- **С-1**: `src/aidnd/plot/` — схема библии + `plot_architect` + валидатор правил + кастинг-матчер
  на placed NPC. Генерация при создании мира (сид — из профиля города). Стенд /plotdebug.
- **С-2**: плот-граф + зацепки через предметы/контракты/сплетни; тик сюжета; акт I играбелен.
- **С-3**: сюжетный слой агенд каста + doom clock; акты II-III; кульминация через боёвку/подземелье.
- **С-4**: хроника-книга (вкладка + скачивание).
- **С-5**: полировка: ложные следы, перевербовка слабого звена, финалы-развилки.

## 8. Вопросы направления (отвечать номерами)

- **С1. Запуск и масштаб.** Сюжет генерится сразу при создании мира — или подключается после
  2-3 дней игры (игрок успел обжиться, знакомые лица «выстрелят» сильнее)? Целевая длина —
  сколько игровых дней/часов на три акта?
- **С2. Сид.** Автоматом из профиля города; выбор игроком из 3 сгенерированных завязок;
  или скрытый (игрок вообще не знает, что сюжет начался, пока не заметит трещину)?
- **С3. Кастинг.** Насколько агрессивно нанизывать на УЖЕ знакомых NPC? (весь каст из
  существующих placed vs новички для верхушки врага). Моё предложение: 80% существующих,
  новички только там, где матчер не нашёл подходящей персоны.
- **С4. Doom clock.** Мягкий (шаги врага — атмосфера и слухи, город не деградирует
  необратимо) или жёсткий (бездействие → плохой финал возможен: культ побеждает, мир
  остаётся жить в темноте — не пермасмерть, но шрам)?
- **С5. Книга.** Литературные главы от хрониста — сразу в первом срезе или потом? (Это
  заметный LLM-расход на каждую сюжетную сцену.)
- **С6. Моральная свобода.** Может ли игрок встать на сторону врага (узнать правду — и
  промолчать за долю, или занять место в иерархии)? Это удваивает развязки, но по-нашему.
- **С7. Размер каста.** Предлагаю 9-15: 4-6 врагов (иерархия из ≥3 уровней), 3-4 союзника,
  2-4 нейтрала. Меньше — иерархии не из чего строить, больше — каша.
