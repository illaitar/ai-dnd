## 1. Мир

**Цель.** Мир живёт по тикам: один тик = симуляция всего = 5 минут игрового времени.
Исключение — бой: в бою время медленнее (раунд — секунды). Всё, что происходит,
сохраняется в БД.

**Сейчас.**
- Часы игрового времени есть (`gt`, минуты), действия тратят время из PB-таблицы
  (шаг 1 мин, реплика 2, торговля 3…). Распорядок дня двигает NPC по фазам
  (утро/день/вечер/ночь).
- Тик живого мира привязан к действию игрока (пошаговость «как за столом»),
  симулируется только текущая локация. Дальние NPC живут грубо: расписание + утренние
  зачистки логовищ.
- Персист: контент мира и рантайм-состояние оба в `data/worlds.db` — известный долг:
  деплой затирает прогресс (надо разнести контент/состояние).

**Решено.**
- ✔ В1.1. LOD: весь город — дешёвая симуляция БЕЗ LLM (потребности/расписание/агенды батчем);
  локация игрока — полный гибрид С LLM.
- ✔ В1.2. Тики продвигаются ТОЛЬКО тратой игрового времени игроком. Реального времени нет.

**Решено (вечер 2026-07-02).**
- ✔ В1.3. Каждое действие = один тик, без кратности/накопления.
- ✔ В1.4. Бой: 1 раунд = 5 секунд игрового времени; мир в масштабе минут стоит.

## 2. Карта

**Цель.** Карта генерируется по конфигу. Дома предсгенерены — для всего, включая
ключевые локации, **подбираем архетипы** (а не генерим здание с нуля). У домов могут быть
суб-локации. В дома можно войти; между домами дороги, разбитые на множество точек.
Путь по дороге **прерывается**, если: (а) игрок видит нечастотное естественное событие
между NPC, (б) игрока тыкают, (в) игрок видит вывеску. Вывеска предлагает занести
ключевое здание на карту. Изначально игрок видит только здание, где появился.

**Сейчас.**
- Граф улиц/узлов, A*, дома-полигоны, дворы, река/поля/хутора (citygraph + citygen).
- Здания насыщаются LLM-фактшитом по хинтам (не архетипы из пула — генерация на месте).
- Суб-локации есть в фактшите (sub_rooms), но игрок по ним не ходит — здание пока
  одно помещение.
- Вход/выход в здания — только что сделано (inside-состояние, карта блокируется внутри,
  кнопки «войти/выйти», мерцание входа).
- Туман войны — только что сделано: метки появляются, когда пришёл или узнал от людей.
  Вывесок-по-пути нет.
- Прерывание пути было в старом контуре (события v0.26), в новом — нет.

**Решено.**
- ✔ В2.1. Как с NPC: БОЛЬШОЙ ПУЛ предсгенерённых зданий-фактшитов (скрипт, LLM офлайн);
  мир при создании раздаёт здания из пула (быстро, без LLM в рантайме).

**Решено.**
- ✔ В2.2. Вывеска по пути ПРЕРЫВАЕТ путь и даёт кнопку «занести на карту».

**Вопросы.**
- В2.3. Суб-локации: движение по комнатам здания = мини-граф внутри здания
  (зал → подвал → второй этаж), с теми же правилами (гейты, ключи)?
- В2.4. «Нечастотное событие» для прерывания пути: порог по редкости решения NPC
  (не рутина) — достаточно ли сигнала malice/agenda, или нужен отдельный скоринг?

## 3. Игрок

**Цель.** Игрок — сущность с инструментами: вызов инвентаря (визуальное окно),
движение по помещениям здания и городу (город — через визуальный интерфейс карты),
и фриформ. Свободно говорит с теми, кто в одной локации. Пока без магии.
«Посмотреть на карту» → отрендерить **пергаментом** знакомую игроку область.

**Сейчас.**
- Единый резолвер `_attempt` (примитив × манера × гейты) + свободный ввод `/act`
  (LLM-интент). Инвентарь-сумка есть (панель, не отдельное окно). Диалог свободный,
  с памятью и тоном (тон реплики двигает отношения — только что).
- Карта постоянно на экране (левая колонка), не по запросу и не пергаментом.
  Известная область — уже фильтруется туманом.

**Решено.**
- ✔ В3.1. ДВА разных UI: рабочая панель-карта (как сейчас) + «достать карту» =
  пергамент-рендер знакомой области по запросу.

**Вопросы.**
- В3.2. Игрок = та же сущность, что NPC (один Body/Combatant/инвентарь — уже почти так).
  Фиксируем: никаких особых веток «если игрок» в симуляции, только в интерфейсе?
- ✔ В3.3 (решено): пока ОДИН стандартный герой; генерация и рост — позже.

## 4. NPC

**Цель.** NPC населены по размеру города — с текущим конфигом ~1000. Живут: расписание,
потребности. Когда игрок в одной точке/помещении с группой NPC — **все активны**
(к обычной симуляции добавляется LLM-прослойка). Впечатление живых людей: говорят между
собой, с игроком если надо, но не сверхактивны — не заговаривают с незнакомцем, едва
тот вошёл. У NPC **нет деления на игрока/не-игрока**: есть список людей в локации,
максимум контекста обо всём.

**Сейчас.**
- Пул ~1000 готовых NPC (механика+персона+портреты), но в мир помещено 100 (draw).
- mind: потребности, эмоции, отношения, память, агенды, decide_hybrid — работает
  в локации игрока. Обезличивание незнакомцев, знакомство, кулдаун обращений
  (только что добавлен — против спама «Слышь, добрый человек» ×4).
- Игрок в mind-мире — уже просто body среди bodies (деления почти нет).

**Решено.**
- ✔ В4.1. Все ~1000 NPC расселяются при генерации мира (дом+работа); draw-механика уходит,
  остаётся LOD симуляции.

**Вопросы.**
- В4.2. «Не сверхактивны»: порог общительности от черт (extraversion) + контекст

- В4.3. NPC↔NPC разговоры при игроке: сейчас скупые. Норма — сколько реплик на тик,

## 5. Предметы

**Цель.** Атрибуты (вес, качество, всё что проработано). Есть **пул предметов**;
новый предмет появляется по необходимости (крафт, награда, редкий спавн у NPC)
и добавляется в пул. Качества как у скинов в CS; качество **«Уникальный»** = предмет
больше никогда не заспавнится из пула при простом подборе. Предметы состоят из
**материалов**; материалы — сами предметы, есть таблица/граф переходов между ними.

**Сейчас.**
- Предмет = фактшит surface (врёт) + hidden (истина под гейтом осмотра) + знание
  наблюдателя; Mod/Gate/Capability; ковка item_smith; качества crude/plain/fine/exquisite
  (→ кость урона в бою). Реальные монеты, ключи, ёмкости.
- Пула нет — каждый предмет куётся на месте. Материалов-как-предметов и графа
  переходов нет. Уникальности нет.

**Решено.**
- ✔ В5.1. Редкость — ОТДЕЛЬНАЯ ось поверх качества выделки; «уникальный» из пула
  не респавнится.
- ✔ В5.2. Граф материалов — таблица данных; крафт = путь по графу с гейтами.
- ✔ В5.3. Редкий спавн — И события, И случайность.

## 6. Квесты

**Цель.** Три источника:
1. **Личная просьба**: NPC просит агента (игрока ИЛИ NPC) с высоким доверием / высокой
   потребностью сделать что-то. У квеста чёткая канва, **твёрдые триггеры активации**,
   возможно компонентные. Может быть несколько этапов.
2. **Доска объявлений** — отдельное «здание» в городе (не рендерить как дом).
   Квесты от конкретных NPC. NPC-прохожие тоже берут — если квест соответствует
   их навыкам и они хотят заработать.
3. **Гильдия приключенцев**: задания по рангу; ранг определяется **удостоверением —
   конкретным предметом**. Может посылать за пределы города в процедурно генерируемые
   помещения.

**Сейчас.**
- Контракты = want-предикаты над реальным состоянием мира (bring/deliver/visit/
  befriend/clear/dead), рождаются из агенд NPC, завершение — фактом мира. Одноэтапные.
- Доска — внутри здания гильдии (совмещена), отдельного столба-доски нет.
- Гильдия есть (здание, clear-заказы по CR, награды из кассы), рангов и
  удостоверения-предмета нет. Подземелья — 5 логовищ на открытой местности,
  процедурных интерьеров нет.
- NPC берут заказы доски и зачищают логова авторезолвом — есть.

**Вопросы.**
- ✔ В6.1 (решено): многоэтапные квесты = ЦЕПОЧКИ предикатов (AND-последовательность;
  деревья позже).
- В6.2. Доска-столб: своя точка на графе (площадь), рендер значком? Кто модерирует —
  любой NPC может повесить объявление за монету?
- ✔ В6.3 (решено): ПЯТЬ рангов, прогрессивно. Чужое удостоверение РАБОТАЕТ, но гильдия
  делает проверку лжи (Insight против Deception; провал = конфискация + чёрная метка).
- В6.4. Процедурные помещения: battlemap-генератор из старого контура (архетип +
  клеточный автомат) поднимаем как генератор подземелий?
