# UI — дизайн экранов (решения)

Живой документ, пара к SLICE.md (§9). Принципы: тёмная палитра (уголь #12141a / панель
#171a22 / линия #2a2f3c / текст #e9e6dd / приглушённый #9aa0ad / золото #d9a441 /
красный #c96a5a / зелёный #7da462), серифы только для «голоса мира» (курсив нарратора,
названия), UI — санс. Никаких лишних экранов: всё, что можно, живёт в трёх колонках.

---

## 1. Главный экран (в игре) — три колонки

**Шапка** (одна строка): ✦ лого · «Локация» · город · время, погода · ♥ hp · зм.

**Левая колонка (480px), сверху вниз:**
- **Карта-панель** — рабочая карта: клик по точке = идти; туман (метки только известных);
  мерцающее кольцо у входа, куда можно войти; внутри здания — затемнена, «ты внутри».
- **Кнопки контекста** (одна строка): [войти: X | ← выйти] [👁 осмотреться (пока не
  осмотрелся)] [🗺 карта] [⌛ ждать].
- **Карточка кубика** — появляется при любом броске: анимированный d20 + строка
  «Навык N±M против СЛ K — успех/провал». Все проверки игры идут сюда.
- **Карточка локации**: имя, одна строка атмосферы (курсив), ёмкости (🔒 = заперто),
  внутри гильдии — доска заказов.

**Центр — единая лента + инпут.** ВСЁ в одном потоке, ничего не вытесняет:
- нарратор — курсив, приглушённый;
- реплика NPC — **аватарка 24px + имя·роль золотом**, если игрок ПОНИМАЕТ, кто говорит
  (знаком или роль очевидна — за стойкой, у наковальни); иначе — **пунктирный кружок «?»
  + дескриптор** («мужчина в рваном плаще»);
- реплика игрока — пузырь справа;
- события мира (лента live) — мелко, приглушённо, вплетены в поток;
- обращения к игроку — как реплики NPC, кликабельны (клик = ответить).

**Диалог НЕ отдельный экран.** Клик по портрету/реплике → над инпутом чип
«говоришь с Ирмой ✕»; ввод идёт ей; ✕ или «отойти» — чип гаснет, ввод снова миру
(/act). Мир продолжает тикать и присылать события во время диалога.

**Правая колонка — сцена:**
- чипы: время · погода · настроение;
- **«кто здесь» = сетка круглых портретов 34px**: знакомые — портрет (тултип имя·роль),
  незнакомые — силуэт «?» (тултип дескриптор), собеседник — золотая обводка,
  переполнение — кружок «+N»; клик = заговорить;
- **одна строка** живого описания сцены (курсив): «за стойкой хозяйка; у очага режутся
  в кости» — собирается из спотов/дел присутствующих;
- 🎒 сумка · N — открывает модал;
- дела — карточки контрактов («логово: гоблин · 6 зм · в путь →»).

## 2. Бой — полноэкранный оверлей
Слева грид: жетоны с hp-полосками (герой золотой, враги красные), подсветка текущего,
клик клетка = шаг / враг = удар. Справа: заголовок (название + среда·CR), **трек
инициативы** (кружки по порядку хода, активный подсвечен), сухой лог, кнопки
[защита] [бежать] [конец хода], строка-подсказка. Победа/поражение — итог в ленту,
оверлей закрывается.

## 3. Пергамент-карта — оверлей по запросу
Кнопка «🗺 карта» или фраза «достаю карту». Весь город в старинной подаче (инверсия в
сепию), метки ТОЛЬКО известных мест, имя города сверху. Клик мимо листа — закрыть.
Доделать: маска неисследованных районов (блёкло), подписи известных зданий курсивом.

## 4. Инвентарь — модальное окно
🎒 в правой колонке. Сетка карточек: имя, вид/качество, количество; клик = осмотр
(инспект уходит в ленту, окно закрывается). В шапке окна — монеты. Доделать: вес,
цвет качества (crude серый → exquisite золотой).

## 5. Лендинг
Карточка по центру: ✦ AI-DnD, строка-девиз, **[Играть]**, настройки (имя героя),
аккаунт (email/гость), инвайт-код + тариф, войти/выйти.

## 6. Логин
Карточка: email, пароль, [Войти] [Регистрация], сообщение об ошибке. Редирект в next.

## 7. Доска гильдии (внутри карточки локации)
Строки заказов: название · вид врага · CR · награда зм · [взять]. Ниже — новости
гильдии приглушённо («Эмса вернулись потрёпанными — логово стоит»).
