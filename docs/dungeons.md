# Подземелья

`src/aidnd/worldgen/dungeongen.py` + `content/cycles.json`. Данж — не арена с волнами, а
**локация мира**: комнаты = зоны живой сцены, поэтому в подземелье работает весь городской
стек — материализация предметов и тайники ([items.md](items.md)), слышимость и разговоры,
разумные обитатели с mind и deal-гейтом, deeds, гильдия ([loop.md](loop.md)).

## Формула (синтез ресёрча 2026-07-06)

Все эталоны (Brogue, Spelunky, Unexplored, Qud, OSR) сходятся: **жёсткие рукотворные
гарантии (циклы, шаблоны, машины, квоты) + дешёвая процедурная вариация внутри + история,
оставляющая следы**. Два симметричных провала: геометрия без причины существования
(donjon-генераторы) и рандом без авторских атомов (ранний Dead Cells).

- **Топология — циклы, не деревья** (Дорманс/Unexplored): вход и цель делят кольцо на две
  дуги-маршрута; словарь циклов = единицы геймплейного смысла; вложение циклов = масштаб.
  Словарь циклов — машинная версия «Jaquaysing the dungeon».
- **Наполнение — таблицы**: B/X-квоты (33% монстр / 17% ловушка / 17% особенность / 33%
  пусто, у пустых 1-к-6 тайник), машины-виньетки Brogue (замок→ключ→риск→награда — таблица
  данных), телеграфирование ловушек, секретки НИКОГДА на критпути, чек-лист комнат фракции.
- **LLM — вкус офлайн в пул, код — геометрия в рантайме** (наука: контроль геометрии LLM —
  3-17%): бриф (история места в 3 слоях «кто построил → что случилось → кто живёт», биты
  вдоль дуги напряжения, enum-архетипы, lock/key-намерения, именования — ни одной
  координаты) + декоратор комнат с уликами по id битов. Метод Qud: историю рационализируем
  задним числом, не симулируем.

## Этап A — СКЕЛЕТ ✔ (2026-07-06, на проде)

Мини-циклическая генерация: кольцо на курс-гриде 9×7 → паттерн из `cycles.json` (данные:
two_paths / lock_and_key / short_danger / hidden_shortcut / foreshadow / double_key)
назначает дугам роли → 2-4 вложения (мини-петля с замыканием на соседа, отросток-награда,
секретный/запертый отросток — ключ на кольце) → Brogue-«пробитые двери» (соседи по гриду,
далёкие по графу → шорткат-цикл) → комнаты на тайлах (прямоугольник/пещера-автомат по
среде; вход-лестница, зал цели) → прямые коридоры.

**Гарантии кодом**: lock/key по построению (ключ на дуге, достижимой без замка) +
BFS-assert «комната × ключи»; критпуть чист от секреток (цель достижима без secret-рёбер);
фильтр Жаке (цикломатика ≥ 2, тупики только с наградой) → следующий под-сид. Детерминизм:
всё от seed, 48 данжей ≈ 70мс. Черновой бумажный рендер (`dungeon_svg`: пергамент,
хэтч, S-секретки, замки, ⚷ ключи, лестница входа) + галерея `/citydebug/dungeons`.

## Дальше

- **Этап B — наполнение + вкус**: стокинг B/X-квотами; машины-виньетки
  `content/dungeon_machines.json`; фракция с ростером отдельно от комнат; ловушки
  (сигнал+триггер+зона+эффект, словарь телеграфов) и тайники через items-hidden; LLM
  `dungeon_architect` (бриф) + `dungeon_decorator` (комнаты с уликами ссылками на биты) —
  офлайн-скриптом в пул; логовища карты получают настоящие данжи по CR/среде.
- **Этап C — бумага + игра**: полный Dyson-рендер (алфавит: двери-коробки, гребёнки
  лестниц, ямы с крестом, вода волнами; сетка 10′), туман по посещённым комнатам, вход из
  логова → план-пергамент, комната = зонная сцена (осмотр/лут/переговоры), бой при встрече
  на существующем гриде (форма комнаты → obstacles), информированный выбор двери (символы:
  сквозняк/рычание — слышимость!), блуждающие как давление времени, restocking 1-к-6 по
  дням, реакция фракции на прошлый рейд.
