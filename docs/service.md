# Service

FastAPI (`server/app.py`), single process; UI — one page `web/play.html` + landing page + login.

## Auth and Sessions

Email+password (argon2) and Google OAuth (authlib); cookie session; `/play` requires a session.
Service database — **Postgres** (users/auth-sessions; unavailable → anonymous demo mode with
warning). User world: cookie → user → `user_worlds` (live.db) → game session
in contextvar (`_S` proxy, `_wid()`); without session API returns 401. Dev/tests:
`AIDND_OPEN_PLAY=1` — shared world without login.

## LLM Limits and Invite Codes

Per-user daily counter — hook `ModelManager.on_call` (each logical call = limit tick;
retries don't recount); daily budget without code — soft stop 402 ('limit today — code or tomorrow'). Invite codes: generated by admin (gencode), activation on landing page,
code = unlimited.

## LLM Error Contract

[Principle 1](README.md) at server boundary: `LLMUnavailable` → **503**, `LLMBadOutput` →
**502**, body `{error, detail, narr:[line to player]}`; `play.html` shows red in feed
('Narrator unavailable — world frozen…'). Transport retries (3×) — inside
`ModelManager.call`.

## LLM Profiles

`inference/profiles.py`: `deepseek` (prod: OpenAI-compatible cloud, parallel enrich per
`DEEPSEEK_CONCURRENCY`) · `local` (Ollama, 1 GPU → sequential enrich) · `hybrid`.
Single entry point — `ModelManager.call(role, …)`; role → (backend, model). Schemas: Ollama —
guided-JSON grammar, OpenAI-compat — `response_format=json_object`.
