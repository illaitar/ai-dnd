# Сервис

FastAPI (`server/app.py`), один процесс; UI — одна страница `web/play.html` + лендинг + логин.

## Auth и сессии

Email+пароль (argon2) и Google OAuth (authlib); cookie-сессия; `/play` только под сессией.
Сервисная БД — **Postgres** (users/auth-sessions; недоступна → анонимный демо-режим с
предупреждением). Мир пользователя: cookie → user → `user_worlds` (live.db) → игровая сессия
в contextvar (`_S`-прокси, `_wid()`); без сессии API отдаёт 401. Дев/тесты:
`AIDND_OPEN_PLAY=1` — общий мир без входа.

## Лимиты LLM и инвайт-коды

Счётчик на пользователя в сутки — хук `ModelManager.on_call` (каждый логический вызов = тик
лимита; ретраи не считаются повторно); дневной бюджет без кода — мягкий стоп 402 («лимит на
сегодня — код или завтра»). Инвайт-коды: генерятся админом (gencode), активация на лендинге,
код = безлимит.

## Контракт ошибок LLM

[Принцип 1](README.md) на границе сервера: `LLMUnavailable` → **503**, `LLMBadOutput` →
**502**, тело `{error, detail, narr:[строка игроку]}`; `play.html` показывает красным в ленте
(«Рассказчик недоступен — мир замер…»). Транспортные ретраи (3×) — внутри
`ModelManager.call`.

## Профили LLM

`inference/profiles.py`: `deepseek` (прод: OpenAI-совместимое облако, параллельный enrich по
`DEEPSEEK_CONCURRENCY`) · `local` (Ollama, 1 GPU → последовательный enrich) · `hybrid`.
Единая точка — `ModelManager.call(role, …)`; роль → (бэкенд, модель). Схемы: Ollama —
guided-JSON грамматикой, OpenAI-compat — `response_format=json_object`.

## UI-карта (play.html)

Постоянная панель-карта слева (SVG, туман войны, клик-движение, мерцание входов) ·
**вход в здание** = панель-карта сменяется бумажным ПЛАНОМ помещения (`/api/play/plan`):
метки NPC по зонам, клик по метке = заговорить, клик по зоне = «подойти» (`/api/play/zone`),
туман 🔒 на запертых комнатах ([locations.md](locations.md)) · «достать карту» = пергамент-
оверлей знакомой области · инвентарь-МОДАЛ · 3D-кубик d20 при проверках · диалог НЕ отрывает
от лупа (реплики в общей ленте с аватаркой; незнакомец — силуэт «?»; чип «говоришь с X» над
инпутом) · «кто здесь» = сетка круглых портретов + одна строка живой сцены · бой —
полноэкранный оверлей ([combat.md](combat.md)) · магический холст ([magic.md](magic.md)) ·
дебаг-стенды `/citydebug` (+`/citydebug/plans` — галерея планов) `/minddebug` `/npcdebug`
(гейт по владельцу) · `/api/play/debuglog` — файловый лог сессии.
