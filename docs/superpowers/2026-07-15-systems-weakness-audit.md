# Аудит слабых мест текущих систем (2026-07-15)

Четыре адверсариальных аудита живого кода (не доков): живой мир · story-слой · механики · инфра.
Каждая находка проверена по коду (file:line в исходных отчётах). Здесь — синтез: кросс-слойные
корни первыми, потом топ по слоям. `[PT]` = подтверждено плейтестом этой сессии.

---

## ТРИ КОРНЯ, всплывшие в НЕСКОЛЬКИХ слоях

### Корень A — «состояние в памяти, которого не переживает рестарт»
Одна и та же болезнь в трёх слоях, деплой = `git reset --hard` + рестарт:
- **gt** — чинили в этой сессии (сквозняк). Но `_npc_save` пишет только rel/needs/memory —
  **агенды НЕ персистятся** (инфра S7, story #2). Рестарт → NPC без агенды → утренний
  `_recheck_overtaken` закрывает принятый квест как «overtaken» без награды. Sift/grievance-квесты
  теряются при каждом деплое.
- **mana_gt / insp_gt / relationships** — та же ленивая запись, потенциально откатываются.
- **транзит-строки** эфемерны (ок), но `_S`-ключи без схемы — тихий дрейф.
**Фикс-направление:** персистить агенды в `save_npc_state`; `_recheck` терпит
missing-but-unadvanced агенду (контракт уже несёт `done_any[0]`).

### Корень B — «аффективно-социальный контур почти разомкнут» (главная находка живого мира)
Механический `appraise()` двигает эмоции ТОЛЬКО от со-присутствия. Дискретные события
(убийство/драка/инцидент при свидетелях) входят лишь **текстом в промпт** — свидетель получает
память, но **ноль страха/гнева** (`_witness_crime`). А то немногое, что накопилось, **никогда не
затухает** (отношения только растут). Отсюда системно и разом три плейтест-находки:
- `[PT]` эмоция-статика на сильных событиях (свидетель бойни невозмутим),
- `[PT]` «незнакомец навсегда» — со-присутствие не растит знакомство (`skip_seed_id` + нет иного пути),
- `[PT]` «никто не заговаривает первым» — в `_MUST_WHY` нет причины «новичок в зале».
Плюс: `feel/need` тулы дают LLM **обнулять свои же нужды/эмоции** абсолютной записью.
**Фикс-направление:** события→`appraise()` для КАЖДОГО свидетеля с реальными дименсиями +
универсальный распад к базовой линии в тике + импульс-приветствие новичка + клампить `feel/need`
до дельт.

### Корень C — «нет достижимого пути прогрессии новичка, а пермасмерть его требует»
Story и механики независимо пришли к одному: конвейер/граф **честно оформлены, но разъединены**.
- Квесты: casting не материализует player-actionable шаг для `wealth`/`affinity` → целые паттерны
  выдают **незакрываемые** квесты (story #1, `courtship_wall`).
- Механики: три рампы новичка сломаны и усиливают друг друга — `[PT]` первый бой невыигрываем
  (безоружный 18hp vs cr0.8: проигрывает даже 1-в-1), **лечебные зелья лечат 0 hp** (heal-атрибут
  без святости), `[PT]` **крафт недостижим** (нет добычи материалов вообще), а экономика **осушается
  в ноль** (30 из 1354 имеют доход) — торговать не на что.
Пермасмерть = полный ресет мира. Чинить только числа боя — мимо: слою нужен **связный контур
прогрессии** (источник сырья → доступное снаряжение → работающие хилы → рециркуляция монет) прежде
чем пермасмерть станет честной.

## ТОП ПО СЛОЯМ (severe-first, за вычетом трёх корней)

### Живой мир
1. Транзит-пешеход невидим для вместимости назначения всю дорогу (`crof`=origin) → синхронный
   перелив-оверсабскрайб на прибытии (шире, чем задокументированный >30-узловой край).
2. Attention economy (Pillar 2) отсутствует → примитив кражи мёртв (`attention` ~никогда <0.4,
   ветка `take_distracted` не срабатывает) — воровство схлопывается в «атака или ничего».
3. Память NPC безгранична (только append, `recall` сканит всё) — O(тиков) рост × 1354 в
   персистентных мирах.
4. Агенды-тупики: `never`/`have:кошель` могут не разрешиться никогда, нет пути отказа/реплана.
5. Проксемика подмешивается в НЕ-социальные утилиты (бегущий тянется к симпатичному прохожему у
   цели бегства).
6. `[PT]` genderless «вошёл(ла)» в churn (косметика, но повсеместно).

### Story-слой
1. Судья (`framing.judge`) — единая точка блэкаута: нечитаемый JSON → `[]` → квест-less день
   (нет salience-фолбэка), усилено `quest_active_max=1`.
2. Апофения-валидатор — хрупкая whack-a-mole на 60+ ручных openers + 4-char стемах с коллизиями;
   легитимное имя отвергается дважды → честное отсутствие.
3. Смерть злодея от третьих рук = халявное завершение (`done_any_met` «как угодно добыто» платит,
   хотя игрок ничего не делал).
4. `[PT]` брошенные диалоговые хуки: спонтанно предложенную NPC работу («замолви словечко») **нельзя
   принять** — контракт только через `_contract_offer`/emergent.
5. `[PT]` freeform-DM обгоняет гео для НЕ-адресованных вопросов: «где кузнец?» в зал не заземляется
   (`_say_aloud` не зовёт geo_answer).
6. Журнал quest-only → текстура мира (встречи, кражи, выученное гео) больше нигде не помнится игроку;
   best-effort `j_beat` тихо роняет биты на LLM-икоте → дыры в нити.
7. `_world_lookup` кап = 3 (не 12) — может отбросить квест-релевантное здание.
8. `failed`-бит определён в журнале, но квест-слой его не эмитит — нет последствий провала.

### Механики
1. `[PT]` **CRITICAL** первый бой невыигрываем (см. корень C).
2. **CRITICAL** лечебные консумаблы лечат 0 hp (heal гейтится святостью, которой в цепочке трав нет).
3. `[PT]` **CRITICAL** authored-крафт недостижим (нет добычи сырья; `node_lookup("сталь")` пуст).
4. Экономика: доход у ~30/1354; цены инфлируют и залипают на 4× капе (хлеб 2→8) — петля бедности.
5. Wild-magic: бесплатная лотерея на 0 мана (`draw_ms` из тела запроса → цена 0; в бою `_taboo` глушится).
6. Данж-софтлок: монстро-комната метит `looted` ДО раннего return → ключ/клад не выдаются
   (re-loot «уже перетряс») — если ключ гейтит цель, инцидент незакрываем.
7. Re-delve сбрасывает loot-состояние → бесконечная ферма золота/предметов.
8. `cyclomatic<1` фильтр режет строковые/малые данжи → salt-churn и **непойманный ValueError → 500**
   на `/delve` (кирпичит принятый контракт) — тот же класс, что чинили солями, но остаточный.
9. Commission кап качества = «plain» (мастер не сдаст fine/exquisite); крафт-worth дефлирует к ~1 монете.
10. Worth оружия развязан с боевой мощью (exquisite 1d10 ≈ crude 1d4 по цене) — крупнейший скачок
    мощи почти бесплатен, инвертирует гир-экономику.
11. `sell()` broke-торговцу отдаёт вещь за 0 (нет гарда `price<=0`).
12. Enchant-активация обходит taboo/время/ману — бесплатный боевой инструмент в открытую в городе.

### Инфра/архитектура
1. **S1 CRITICAL** блокирующая многосекундная LLM-работа внутри `async`-эндпоинтов на одном
   воркере — один тик игрока морозит весь процесс для всех. Потолок масштаба И несущее допущение,
   маскирующее остальные баги.
2. `[PT]` S2 один провайдер, неприпиненная модель (chat→v4-flash сама сменилась), нет фолбэка →
   баланс-аут = весь прод лёг (было в сессии).
3. S3 дневной LLM-лимит недосчитывается: think_one/plan_agenda в тредах не наследуют contextvars →
   `_UID=None` → эти тики не списывают квоту.
4. S4 та же дыра contextvars = латентная кросс-мировая порча (треды падают в shared wid=1) — одна
   рефакторинг-правка от записи чужих данных в мир 1.
5. S5 деплой без истории миграций live.db (только `CREATE IF NOT EXISTS`) — новая колонка/смена пула
   → тихие сбои чтения у существующих миров.
6. S8 SQLite без WAL, один общий live.db, коннект на операцию — при фиксе S1 (офлоад в треды)
   каждая запись глобально лочит БД на 30с.
7. S9 `_SESS` безграничен, без TTL/LRU — footprint растёт, cold-miss пересобирает весь мир.
8. S10 реплей растёт без ротации + логирует сырой ввод игрока (PII на проде).
9. S6/S13 мегафайлы (`world.py` 1395, `freeform.py` 653) + `_S` без схемы = амплификация правок,
   тихий дрейф ключей.
10. S11 нет метрик/алертов — аутэйдж S2 заметили игрой, не алертом.
11. S12 `LIVE_CONCURRENCY=64` может само-заддосить провайдера (429 → 503 игроку).
12. S14 тест-suite не моделирует async hot-path и не сбрасывает singleton'ы между тестами (класс
    утечки `_STORE`).

## Рекомендованный порядок (по рычагу × риску)

**Тир 1 — делает игру играбельной и честной (пермасмерть требует):**
1. Контур прогрессии новичка (корень C): добыча сырья + чинить heal-атрибут + гир-рампа +
   рециркуляция монет; ПОТОМ тюнить числа боя. Иначе первый бой = гарантированный ресет.
2. Персист агенд + терпимый `_recheck` (корень A): иначе каждый деплой стирает принятые квесты.

**Тир 2 — оживляет мир по-настоящему:**
3. Замкнуть аффективный контур (корень B): события→appraise всем свидетелям + распад + приветствие
   новичка + клампы feel/need. Разом чинит 3 плейтест-находки.
4. Достижимость завершения квестов: reachability-гейт зеркально апофении + якорь завершения на
   строку контракта.

**Тир 3 — прежде чем звать игроков (масштаб/надёжность):**
5. S1: `await asyncio.to_thread` для тиков + WAL на sqlite (S8) вместе — иначе фикс S1 обнажит локи.
6. Припинить модель + фолбэк-путь нарратора (S2); метрики+алерт на устойчивый 503 (S11).
7. Contextvars в тредах (S3/S4): квота и изоляция миров.

**Тир 4 — дизайн-долг:** attention Pillar 2, распад памяти, распил world.py/freeform.py, миграции
live.db, ротация+PII реплея.
